## 初回起動

1. 配布された URL (例: `https://watashi.internal/install/Watashi.Client.application`) をブラウザで開きインストール (初回のみ)
2. スタートメニュー → 「Watashi」を起動
3. 起動すると **ログイン画面** が表示される（接続先サーバは配布時に設定済みのため、利用者が入力する項目はありません）

> 💡 **起動は必ずスタートメニュー / デスクトップの「Watashi」から。**
> 起動のたびに自動でバージョン確認が行われ、新しい版があればその場で適用されてから起動します (操作は不要)。

```
┌──────────────────────────────┐
│ ユーザー名: [____________]   │
│ ☐ このPCを記憶する           │
│       [次へ]                 │
│ [接続テスト]                 │
└──────────────────────────────┘
```

4. **ユーザー名 (GID)** を入力して「次へ」

- 「**このPCを記憶する**」にチェックを入れると次回から自動ログイン (HTTP/HTTPS どちらでも利用可、HTTP では平文通信の警告ツールチップが付く)

「次へ」を押すと、次のどちらかの画面に進みます。

> ユーザー名の英字は大文字小文字を区別しません。たとえば `g012345` と `G012345` は同じユーザーとして扱われます。

### はじめて使うとき (初回パスワードの設定)

まだパスワードを決めていない場合、**「初回パスワードの設定」** 画面が出ます。Windows のログオン情報でご本人であることが自動的に確認されるため、管理者から初期パスワードを受け取る必要はありません。

```
┌──────────────────────────────────────┐
│ 初回パスワードの設定                 │
│ G012345 さん、ようこそ。             │
│                                      │
│ 新しいパスワード:     [__________]   │
│ 新しいパスワード(確認):[__________]  │
│      [設定してログイン]              │
└──────────────────────────────────────┘
```

- 12 文字以上、英大文字 + 英小文字 + 数字 + 記号を必ず含むこと
- 例: `Spring2026!Welcome`
- ここで決めたパスワードがそのまま本パスワードになります (直後にもう一度変更を求められることはありません)
- 設定するとそのままメイン画面に進みます

> 💡 この画面が出ず、いきなりパスワード入力欄が出た場合は、ご利用の PC で Windows の本人確認ができない環境です。管理者に連絡して初期パスワードを発行してもらってください。

### 2 回目以降 (通常のログイン)

パスワード入力欄が出ます。

- パスワード欄の右端の **👁 目玉アイコン** を押すと、入力中のパスワードを平文表示できる (打ち間違い確認用)。もう一度押すと再びマスク
- パスワード残り日数が 14 日以内なら警告メッセージ
- 有効期限切れ / 管理者がパスワードを発行した直後は、**パスワード変更画面** が強制表示されます

5. **メイン画面** に進む

## 日常利用

メイン画面のレイアウト:

```
┌──────────────────────────────────────────────────────────────────┐
│ ⛩ Watashi  CIFS ファイル管理       👤 alice  ⟳ ◐ ⚙ 🔑 ▣ ⏻ ⓘ│
├──────────────────────────────────────────────────────────────────┤
│ [⬆ アップロード] [⬇ ダウンロード] │ 📁＋新規フォルダ │ 🗑 削除 │
├─────────────────────────────────────┬────────────────────────────┤
│ 💻 ローカル (このPC)                │ ⛩ リモート  場所:[経理部▼] │
│ ◀ ▶ ⬆ ⟳  D:\work               移動│ ◀ ▶ ⬆ ⟳ /dept-A/2026   移動│
├─────────────────────────────────────┼────────────────────────────┤
│  📁 ..                              │  📁 ..                     │
│  📁 ProjectA       2026/05/01 ...   │  📁 reports/               │
│  📄 memo.txt   1KB 2026/05/20 ...   │  📄 budget.xlsx 500KB ...  │
├─────────────────────────────────────┴────────────────────────────┤
│ 転送中: report.xlsx ████████░░ 80%                                │
├──────────────────────────────────────────────────────────────────┤
│ ● 接続中 (HTTPS)  │ アップロード完了 │ ローカル: D:\work │ admin │
└──────────────────────────────────────────────────────────────────┘
```

- **テーマ**: メイン画面右上の月／太陽ボタンでライト／ダークを切り替え。設定は次回起動時のログイン画面にも適用
- **ヘッダー**: 鳥居ロゴ + Watashi、右上にユーザー名・プロトコル・月／太陽のテーマ切替・個人設定・管理ボタン(管理者のみ)・更新・ログアウト・情報
- **左ペイン (ローカル)** 💻: あなたの PC のフォルダ
- **右ペイン (リモート)** ⛩: 中央サーバー経由で見える CIFS 共有 (場所ドロップダウンで切替)
- **リモート一覧**: 最初に 500 件を表示し、残りがある場合だけ **さらに読み込む** で 500 件ずつ追加
- **場所の全文**: リモートの場所ドロップダウンへマウスを置くと、現在選択中の表示名・ホスト・共有・許可ルートを表示
- **行ホバー** で長いファイル名・パスがツールチップで全文表示
- 最大化は現在のモニターの作業領域全体を使い、復元ボタンで最大化前の大きさに戻る
- **F5** で両ペイン同時更新、**Backspace** で親フォルダ、**Delete** で削除(確認ダイアログ付き)
- ステータスバー: 接続プロトコル ●、直近の操作/エラー (時刻 + 発生元)、ログイン中ユーザー

## 個人設定

メイン画面右上の **⚙ 個人設定** から、このWindowsユーザーで使用する設定を変更できます。

| 分類 | 設定 | 動作 |
|---|---|---|
| 起動 | ローカルペイン | 前回開いていたフォルダ、または指定した固定フォルダから開始 |
| 起動 | リモートペイン | 未選択、前回開いていた場所、指定したお気に入りから開始 |
| 表示 | テーマ | ライト／ダーク。右上の月／太陽ボタンでも即時切替可能 |
| 表示 | 並び順 | オンにするとローカル／リモートで最後に選んだ列と昇順／降順を記憶 |
| ファイル操作 | ローカル削除 | Windowsのごみ箱を使うか、完全削除するかを選択 |

- 固定ローカルフォルダは「現在地」または「参照...」から指定できます。保存時点で存在しないパスは登録できません
- 起動後に固定フォルダが利用できなくなった場合は、前回のフォルダまたはWindowsユーザーフォルダを表示して警告します。固定設定自体は残るため、次回利用可能になれば再び開きます
- 指定したリモートのお気に入りや前回場所は、現在の権限内にある場合だけ開きます。権限がなくなった保存場所は自動的に除外されます
- 「最近使ったリモート場所を消去」は履歴と前回場所を削除しますが、お気に入りは残します
- 「個人設定を初期値に戻す」は、開始位置・テーマ・削除方法・並び順設定を戻します。お気に入りと履歴は削除しません

設定は `%LocalAppData%\Watashi\settings.json` に保存され、WatashiのログインIDではなく、使用中のWindowsユーザーごとに適用されます。

## ファイル操作

### フォルダ移動

- 一覧の項目を **ダブルクリック** で展開
- `..` で親フォルダに戻る (権限の最上位では `..` がグレー)
- パス欄に直接入力 + Enter でジャンプも可能
- ローカルペインのパス欄の隣の **📂 ボタン** で Windows のフォルダ選択ダイアログ (エクスプローラ風) が開き、ツリーから目的のフォルダを選んで一発でジャンプできる
- 別フォルダへの移動が成功すると、そのペインの**絞り込み欄だけ**空になる。列見出しで選んだ並び順は維持

### アップロード (PC → リモート)

1. 左ペイン (ローカル) で送りたいファイルを選択
2. 右ペインで送信先フォルダを開く
3. ツールバーの **⇨ UP** ボタンを押す
4. 進捗バーで状況を確認、完了で「アップロード完了」表示

### ダウンロード (リモート → PC)

1. 右ペインで取得したいファイルを選択
2. ツールバーの **DL ⇦** ボタンを押す
3. 保存ダイアログで保存先を選択
4. 進捗バーで状況を確認

> 💡 **中途半端なファイルは正式名にならない**: ダウンロードは専用の一時ファイルに書き、SHA-256 検証後に正式名へ原子的に切り替えます。通信断では再開位置を保持し、一時的な通信障害は自動再試行します。不要になった失敗ジョブを転送センターから削除すると一時ファイルも回収されます。

### 削除

- リモートを消す: 右ペインで選択 → **🗑 リモート削除**。管理ごみ箱へ移動され、保管期間内はヘッダーの「ごみ箱」から復元できます
- ローカルを消す: 左ペインで選択 → **🗑 ローカル削除** (同上)
- Delete キーでも削除可

### リモートコピー（移動はありません）

- 右ペインで1件以上を選択し、右クリック → **別のフォルダーへコピー...**
- コピー先の絶対パスを入力して確認します。同名項目がある場合は安全な別名になります
- フォルダーはコピー完了後にだけ公開されます。途中失敗時に未完成フォルダーを正式名で残しません
- 事故防止のため、フォルダー間の**移動**機能はありません。コピー元は常に残ります

### リネーム / フォルダ作成

- **リネーム**: `F2` キーで選択中のファイル/フォルダ名を変更 (右クリック → リネーム... でも同じ)
  - 同じフォルダ内でのリネームのみ可。`/` `\` は名前に含められない
  - リモートでは「許可ルートそのもの (例: `/dept-A`)」と「親ディレクトリ変更」はサーバが拒否する
- **新規フォルダ**: ツールバーの **📁＋ 新規フォルダ (リモート/ローカル)** または 右クリック → 新規フォルダ...
  - どちらもフォルダ名のプロンプトが出る

### 右クリックメニュー

ファイル一覧の上で右クリックすると、選択中アイテムに対する操作が一覧で出る:

| メニュー | ローカル | リモート | 内容 |
|---|---|---|---|
| 開く / 展開 | ✓ | ✓ | フォルダなら展開、`..` なら親へ |
| アップロード / ダウンロード | アップロード | ダウンロード | ツールバーのボタンと同じ動作 |
| リネーム... (F2) | ✓ | ✓ | 同じフォルダ内で名前変更 |
| 削除 (Del) | ✓ | ✓ | 確認ダイアログ付き |
| 新規フォルダ... | ✓ | ✓ | フォルダ名のプロンプト |
| エクスプローラで表示 | ✓ | — | Windows のエクスプローラで選択状態で開く |
| パスをコピー | ✓ | ✓ | 選択中アイテム (なければ現在のフォルダ) のフルパスをクリップボードへ |

### 制約事項 (権限による)

- 自分の権限テンプレートで許可されていない操作はエラー
- **許可ルートそのものは削除/リネーム不可** (例: `/dept-A` 自体は消せない、中身は OK)
- **リネームでは親ディレクトリ変更不可** (フォルダを跨いだ移動は禁止)

## パスワード変更

通常時は、メイン画面右上の **🔑 ボタン (パスワード変更)** からいつでも変更できます。
現在のパスワード、新しいパスワード、確認を入力して「変更」を押してください。

有効期限切れ / 管理者が初期パスワードを発行した場合は、ログイン後に同じ画面が強制表示され、変更が完了するまでメイン画面へ進めません。アプリを開いたまま有効期限を迎えた場合も、次の認証更新時に強制変更画面へ切り替わります。

パスワードを忘れた場合は管理者に連絡してください。対応は 2 通りあります。

- **初回設定に戻してもらう** — もう一度「初回パスワードの設定」画面が出て、ご自身で決め直せます (パスワードを人づてに受け取る必要がありません)
- **初期パスワードを発行してもらう** — Windows の本人確認ができない環境の場合。受け取ったパスワードで一度ログインし、その場で変更します

各入力欄 (現在のパスワード / 新しいパスワード / 確認) はすべて **👁 目玉アイコン** で表示確認可能。
新しいパスワードは「確認」と同じ値を入力してください。

ポリシー:
- 12 文字以上
- 英大文字 1 文字以上
- 英小文字 1 文字以上
- 数字 1 文字以上
- 記号 1 文字以上

NG 例: `password123`, `Short1!`, `nouppercases123!`
OK 例: `Spring2026!Welcome`, `Watashi#Tool-2026`

## このPCを記憶する (自動ログイン)

ログイン画面の **このPCを記憶する** を ON にしてログインすると、
次回起動から **PC 名 + Windows ユーザー名 + デバイストークン** で自動ログイン。

仕様:
- **HTTP/HTTPS どちらでも利用可能** (HTTP では平文通信なので、ツールチップに警告)
- 1 ユーザーあたり既定 3 台（管理者が 1〜20 台で設定）まで登録可能。同じ端末を再登録したときだけ古いトークンを失効
- Windows Credential Manager に暗号化保存 (他の Windows ユーザーからは読めない)
- ヘッダーの **信頼端末** から自分の登録端末を一覧し、不要な端末だけを失効可能
- 管理者が「全デバイス失効」を行うと無効化される (退職者対応など)
- HTTP 環境では本番想定では非推奨。`Auth:AllowHttpForAutoLogin` が `false` のサーバーには HTTP 自動ログインを拒否される

サーバーで Windows SSO が有効な場合は、ログイン画面の **Windowsアカウントでログイン** からパスワードなしで入れます。無効・不成立の場合も従来のID/パスワードログインはそのまま利用できます。

## ログアウト

ヘッダー右上の **⏻ ボタン** をクリック (確認ダイアログ付き)

- サーバー側のリフレッシュトークンを失効
- Credential Manager のデバイストークンも削除
- ログイン画面に戻る

**アイドルタイムアウト**: 操作なしで自動ログアウト。デフォルト 30 分（管理者が社内ポリシーで変更可能）。

パスワード変更・初回設定への差し戻し・管理者権限変更・アカウントロックなどがサーバー側で行われた場合も、安全のため操作中にセッションが切れてログイン画面へ戻ることがあります。表示された理由に従い、必要なら管理者へ連絡してから再ログインしてください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| ログイン画面で「アカウントがロックされています」 | 連続で失敗するとロック (既定 15 回)。管理者に連絡してロック解除依頼 |
| 「ユーザー名またはパスワードが違います」が連続 | 大文字小文字、数字混じりをよく確認。CapsLock 注意 |
| 「しばらく時間を置いてから...」「429 Too Many Requests」 | 短時間のログイン試行が多すぎ。1 分待ってから再試行 |
| パスワード変更画面が出る | 90 日経過/管理者リセット。新しいパスワードを設定 |
| 操作中に「パスワードが変更されたため、セッションが無効」と出る | パスワード変更・管理者権限変更・初回設定への差し戻しが反映された。新しい状態で再ログイン |
| 操作中に「アカウントがロック」と出る | 発行済みセッションも即時停止される。管理者にロック解除を依頼してから再ログイン |
| リモートペインが空 | 自分に権限が割り当てられていない可能性。管理者に依頼 |
| 「ホスト/共有が見つかりません」 | サーバー設定で削除された可能性。管理者に確認 |
| 「リネームでは親ディレクトリを変更できません」 | 仕様。同じフォルダ内でのリネームのみ可 |
| 大きなファイルが途中で止まる | 転送センターで状態と次回再試行時刻を確認。一時障害は自動再試行され、アプリ再起動後も確定済み位置から再開可能 |
| 自動ログインがすぐ切れる | サーバーが HTTP 自動ログインを許可していない可能性。管理者に `Auth:AllowHttpForAutoLogin` を確認、または HTTPS で接続し直す |
| 自動ログイン中にいきなり「再ログインしてください」 | パスワード/権限/ロック状態の変更、端末失効、または盗難検知。表示理由を管理者に伝え、必要なら信頼デバイスを再登録 |
| 起動時に更新の進捗ダイアログが出る | ClickOnce 自動更新。新しい版を適用してから起動する (必須更新のためスキップ不可) |
| 起動しても新しい版にならない | 配布サーバーに到達できない可能性。しばらくしてからスタートメニュー / デスクトップの「Watashi」ショートカットから起動し直す |
