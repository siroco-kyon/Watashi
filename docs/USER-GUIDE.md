## 初回起動

1. 配布された URL (例: `https://watashi.internal/install/Watashi.Client.application`) をブラウザで開きインストール
2. スタートメニュー → 「Watashi」を起動
3. **接続設定** ダイアログが表示される

```
┌────────────────────────────────────┐
│ 接続設定                            │
├────────────────────────────────────┤
│ サーバーURL: https://watashi:8443  │
│ プロトコル:  ◉ HTTPS  ○ HTTP       │
│                                    │
│   [接続テスト]   [保存して閉じる]   │
└────────────────────────────────────┘
```

- **サーバーURL**: 情シス担当から伝えられた URL を入力
- **プロトコル**: 通常は HTTPS を選択
- **接続テスト** で「✓ 接続できました。」が出れば OK → **保存して閉じる**

4. **ログイン画面** が出る

```
┌──────────────────────────────┐
│ ユーザー名: [____________]   │
│ パスワード: [____________]   │
│ ☐ このPCを記憶する           │
│       [ログイン]             │
│ [接続設定]                   │
└──────────────────────────────┘
```

- 初回パスワードは管理者から伝えられる
- 「**このPCを記憶する**」にチェックを入れると次回から自動ログイン (HTTPS の時のみ選べる)
- パスワード残り日数が 14 日以内なら警告メッセージ

5. 初回ログインの後 (または期限切れ時) は **パスワード変更画面** が強制表示される
   - 12 文字以上、英大文字 + 英小文字 + 数字 + 記号を必ず含むこと
   - 例: `Spring2026!Welcome`

6. 変更完了で **メイン画面** に進む

## 日常利用

メイン画面のレイアウト:

```
┌─────────────────────────────────────────────────────────┐
│ ファイル(F) 管理(A)* ヘルプ(H)                          │
├─────────────────────────────────────┬───────────────────┤
│ ローカル: C:\Users\you\Documents    │ 場所:[経理部 ▼]   │
│                                     │ パス: /dept-A/2026│
├─────────────────────────────────────┼───────────────────┤
│ 📁 ..                              │ 📁 ..             │
│ 📁 ProjectA       2026/05/01 ...   │ 📁 reports/       │
│ 📄 memo.txt   1KB 2026/05/20 ...   │ 📄 budget.xlsx... │
│ 📄 photo.jpg 500KB ...              │                   │
├─────────────────────────────────────┴───────────────────┤
│ [⇨ UP] [DL ⇦] [リモート削除] [ローカル削除] [新規フォル] │
├─────────────────────────────────────────────────────────┤
│ 転送中: report.xlsx ████████░░ 80%                       │
├─────────────────────────────────────────────────────────┤
│ 接続: HTTPS  ユーザー: alice                             │
└─────────────────────────────────────────────────────────┘
```

- **左ペイン (ローカル)**: あなたの PC のフォルダ
- **右ペイン (リモート)**: 中央サーバー経由で見える CIFS 共有
- 上部メニューの「**管理(A)**」は管理者のみ表示される
- ステータスバーに 接続プロトコル / 自分のユーザー名 が出る

## ファイル操作

### フォルダ移動

- 一覧の項目を **ダブルクリック** で展開
- `..` で親フォルダに戻る (権限の最上位では `..` がグレー)
- パス欄に直接入力 + Enter でジャンプも可能

### アップロード (PC → リモート)

1. 左ペイン (ローカル) で送りたいファイルを選択
2. 右ペインで送信先フォルダを開く
3. ツールバーの **⇨ UP** ボタンを押す
4. 進捗バーで状況を確認、完了で「アップロード完了」表示

### ダウンロード (リモート → PC)

1. 右ペインで取得したいファイルを選択
2. ツールバーの **DL ⇦** ボタンを押す
3. 保存ダイアログで保存先を選択
4. 進捗バーで状況を確認

### 削除

- リモートを消す: 右ペインで選択 → **リモート削除**
- ローカルを消す: 左ペインで選択 → **ローカル削除**

### リネーム / フォルダ作成

- リネーム: F2 キー (または右クリックメニュー、今後追加)
- 新規フォルダ: ツールバーの **新規フォルダ (リモート/ローカル)**
  - リモートではダイアログでフォルダ名を入力

### 制約事項 (権限による)

- 自分の権限テンプレートで許可されていない操作はエラー
- **許可ルートそのものは削除/リネーム不可** (例: `/dept-A` 自体は消せない、中身は OK)
- **リネームでは親ディレクトリ変更不可** (フォルダを跨いだ移動は禁止)

## パスワード変更

通常時はメニューからアクセス (今後追加予定)。
有効期限切れ / 管理者がリセットした場合は次回ログイン時に自動表示。

ポリシー:
- 12 文字以上
- 英大文字 1 文字以上
- 英小文字 1 文字以上
- 数字 1 文字以上
- 記号 1 文字以上

NG 例: `password123`, `Short1!`, `nouppercases123!`
OK 例: `Spring2026!Welcome`, `Watashi#Tool-2026`

## このPCを記憶する (自動ログイン)

ログイン画面の **このPCを記憶する** を ON にしてログインすると、
次回起動から **PC 名 + Windows ユーザー名 + デバイストークン** で自動ログイン。

仕様:
- **HTTPS 接続時のみ有効** (HTTP ではチェックボックスがグレーアウト)
- 1 ユーザー = 1 デバイスのみ。別の PC でチェック ON にすると古い方は失効
- Windows Credential Manager に暗号化保存 (他の Windows ユーザーからは読めない)
- 管理者が「全デバイス失効」を行うと無効化される (退職者対応など)

---

## ログアウト

メニュー → **ファイル(F)** → **ログアウト**

- サーバー側のリフレッシュトークンを失効
- Credential Manager のデバイストークンも削除
- ログイン画面に戻る

**アイドルタイムアウト**: 30 分操作なしで自動ログアウト。

## 困ったとき

| 症状 | 対処 |
|---|---|
| ログイン画面で「アカウントがロックされています」 | 5 回連続で失敗するとロック。情シスに連絡してロック解除依頼 |
| 「ユーザー名またはパスワードが違います」が連続 | 大文字小文字、数字混じりをよく確認。CapsLock 注意 |
| パスワード変更画面が出る | 90 日経過/管理者リセット。新しいパスワードを設定 |
| リモートペインが空 | 自分に権限が割り当てられていない可能性。管理者に依頼 |
| 「ホスト/共有が見つかりません」 | サーバー設定で削除された可能性。管理者に確認 |
| 「リネームでは親ディレクトリを変更できません」 | 仕様。同じフォルダ内でのリネームのみ可 |
| 大きなファイルが途中で止まる | ネットワーク帯域 / セッション切れの可能性。再試行 |
| 自動ログインがすぐ切れる | 接続が HTTP の場合は不可、HTTPS で再設定 |
| 「新しいバージョンがあります」と出る | ClickOnce 自動更新。次回再起動で適用される |
