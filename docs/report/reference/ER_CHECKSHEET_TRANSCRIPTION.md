## 本文

### 序論

- [ ] 課題＋（動機）、目的、これまでの経緯ないし背景が記載されている。
  - 何が現状の問題かが記載されている。
  - なぜこの業務を行ったのか理由が明確である。
  - 上記の項目が適切に記載されており、経験の浅いエンジニアでもなぜこのERが必要なのかを理解できること。
- [ ] アプローチ、各章の簡単な内容が記載されている。
  - ERの構成について述べられていること。
  - もしくは、序論以後のERの論理の展開について展望できる内容が記載されていること。
- [ ] ゴール、明らかにすべきことが記載されている。
  - 「何をどこまで」が記載されていること。

### 実験／理論

- [ ] ストーリーが明確であり、かつストーリーに沿った検討が明快になされている。
- [ ] 検討方法が具体的に明示されている。
  - 使用したデータ、装置、ツールとその手法が明確で、再現が可能な情報が記載されていること。
- [ ] 目的から結論を得るための検討方法（実験およびシミュレーション等）の選択が適切である。
  - 選択した手法が必然的であると判断出来ること。
- [ ] 根拠のある仮説に基づいている。
  - （仮説が記載されている場合のみ）仮説に無理がなく、論理に飛躍がないこと。

### 結果／考察

- [ ] 論旨が円滑につながっている。論旨展開は結果の範囲内である。
  - あくまでERに記載される結果から必然的に導かれない「思い込み」、「想像」による論理の飛躍がないこと。
- [ ] 結果から結論に至る論拠が明瞭である。
  - 次に続く結論を導き出すのに必要な、結果に対する考察がなされていること。
- [ ] 論拠を仮説に求める場合はその根拠が明示されている。
  - 既に証明されている理論やデータを用いて、仮説が単なる思い込みではないことを証明していること。
- [ ] 考察すべき点が網羅されており抜けがない。
  - 結論に対する反証の余地がない考察が行われていること。このERが扱うべき全てのテーマについて、考察が網羅されていること。

### 結論（まとめ）／引用、参照文献

- [ ] 概要から考察に至る本文の内容を余すところなく簡潔にまとめている。
  - 各章でどういうトピックを扱ったのかが簡潔にまとめられていること。
  - もしくは、ER全体の論理（ロジック）を簡潔に見直すことができる文章が記載されていること。
- [ ] 明らかになったことを明確に示している。
  - 本ER内で、新たに分かったことが明確にされていること。
- [ ] 業務への貢献（研究、開発、生産）が明確に結論されている。
  - 次の検討に対する下地としての役割など、直接の生産性の向上でなくとも、将来の対してどのような位置付けの成果であるかが記載されていること。
- [ ] 今後の課題や進め方を明確に示している。
- [ ] 引用文献、参照文献の選択は適切である。
  - （ER全体について）必要な過去のERを含む参考文献が引用されている。

## 書き方

- [ ] 文体が統一されている（話し言葉が混在していない）。
  - 「です、ます。」調ではないこと。
- [ ] 担当分野以外のエンジニアの理解を促すための記述がなされている。
  - 経験の浅いエンジニア（1年～2年）でも、大半の内容を習得・理解できること。
- [ ] 簡潔明瞭な文章で記述されている。
  - 1文章（センテンス）1論旨が守られていること。
- [ ] 数式の説明は変数の意味を余すところ無く記述している。
- [ ] 章立て、節立て、全体構成はバランス良く適切である。
  - 章立てが多すぎず、少なすぎず、適切な区切りをしていること。本文の論旨にあった論理構造をしていること。
- [ ] ページ数が多い場合には、目次を追加している。
  - 目次が最終稿とちゃんと整合がとれていること。
- [ ] 誤字、脱字、スペルミスがない。
- [ ] 引用／参照の体裁は整っている。
- [ ] 文中初めて記載する略語は、略さずに書かれている（注釈でも可）。
  - （緒言で既出でも本文では欧文の綴（つづ）りを、略さずに書かなければならない）
  - 略号や省略記載は、「概要」でスペルアウトすること。
  - 「序論」以後でも、最初に出た時は都度スペルアウトすること。
- [ ] 謝辞は必要かつ十分な範囲である。
- [ ] 図表は本文との対応が取れている。
  - 全ての図表は、本文中から1度以上参照されていること。
  - 本文中に、なぜその図表が必要であるかが記載されていること。
- [ ] 図表の情報が正確且つ的確に伝わるように構成されている（ビジーすぎない）。
- [ ] 標題は表の上側、図の下側に付加されている。
  - 標題がついていて、かつ図表の内容を適切にあらわしていること。
- [ ] 単位が明記されている。
  - 全ての単位付き数値は、単位が記載されていること。

## 転記上の注記

- 原資料中の「延べられている」「出来る」「事」「且つ」などの表記は、校正せず残している。
- 本レポートでは、原資料の「実験／理論」を「要件・設計・実装・検証方法」、「結果／考察」を「実装結果・検証結果・設計判断の評価」として適用する。
