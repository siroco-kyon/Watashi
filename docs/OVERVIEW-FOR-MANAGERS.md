# Watashi とは — ツール紹介 (管理職・非技術者向け)

> **ひとことで:** 社内のファイルサーバーへ、**安全に・記録を残しながら**アクセスするための社内専用ツールです。

この資料は、技術に詳しくない方にツールの目的と価値をつかんでいただくためのものです。
専門的な設定や操作は別資料 ([情シス向け](ADMIN-GUIDE.md) / [利用者向け](USER-GUIDE.md)) にあります。

---

## 1. これは何をするもの？

- 社員が、社内のファイルサーバー (共有フォルダ) のファイルを、**専用アプリから安全にやり取り**できるようにする道具です。
- 画面は「**左に自分の PC、右に社内サーバー**」の 2 画面構成。マウス操作でアップロード/ダウンロードします。
- 昔ながらのファイル転送ソフト (例: FFFTP) を、**より安全で・管理しやすくした後継**とお考えください。

```
   ┌─────────────────┐                 ┌─────────────────┐
   │  自分の PC       │   ⇄ ファイル ⇄  │  社内ファイル    │
   │ (専用アプリ)     │                 │  サーバー        │
   └─────────────────┘                 └─────────────────┘
        左の画面                              右の画面
```

---

## 2. どんな困りごとを解決する？

| これまでの困りごと | Watashi でどうなる |
|---|---|
| 誰がどのファイルを触ったか分からない | **すべての操作が自動で記録**される |
| 全員があらゆるフォルダを見られてしまう | **人ごと・フォルダごと**にアクセス権を設定 |
| 退職者のアクセスがいつまでも残る | 管理画面から**ワンクリックで無効化** |
| パスワードが弱い / 使い回される | **強さと有効期限を全社で強制** |
| サーバーに直接つなげない (踏み台が必要) | **踏み台サーバー越しのアクセスに対応** |

---

## 3. 主な機能 (ざっくり)

- 📤📥 **ファイルの送受信** — 大きなファイルでも扱えます
- 🔑 **細かいアクセス権** — 人ごとに「読むだけ / 書き込みOK / 削除OK」などを設定
- 📝 **操作の記録 (監査ログ)** — 「いつ・誰が・何をしたか」をすべて記録、表計算ソフト用に出力も可能
- 👥 **管理画面** — ユーザー追加・権限設定・記録の確認 (一般社員には表示されません)
- 🔄 **自動更新** — 新しい版が出ると、社員の PC に自動で配られます

---

## 4. 安全性 — 情報を守るしくみ

経営・管理の視点で押さえておきたいポイントです。

- **通信は暗号化** されます (途中で盗み見されない)
- サーバーに預けるパスワード類は **暗号化して保管**
- **全操作が記録** され、後から「誰が何をしたか」を追える
- パスワードは **一定の強さを必須** + 定期変更
- 不審なログインは **自動でブロック** (連続失敗でロック / 試行回数を制限)
- 一般社員には **管理機能を一切見せない**
- **接続先は管理者が固定** — 接続先サーバは配布時に管理者が決めて固定し、利用者は変更できません (誤接続・不正接続の防止)
- データは **すべて社内で完結** — 外部のクラウドサービスには出ません

---

## 5. 全体の構成 (イメージ)

```
 ┌──────────────┐   暗号化通信   ┌──────────────┐   (必要なら)   ┌──────────────┐
 │ 社員の PC    │ ───────────▶ │ 中央サーバー │ ─ 踏み台経由 ─▶ │ 社内ファイル │
 │ 専用アプリ   │ ◀─────────── │ (社内に1台)  │                │ サーバー     │
 └──────────────┘               └──────────────┘                └──────────────┘
```

- **中央サーバー**: 社内に 1 台。アクセス権の管理・記録・受け渡しの中継を担います。
- **踏み台サーバー** (任意): セキュリティ上、直接つなげない場所へ中継してアクセスするための中継役。

---

## 6. 導入に必要なもの

- 社内に **中央サーバー 1 台**
- (必要に応じて) **踏み台サーバー**
- 社員 PC に **専用アプリ** (自動で配布・更新されます)
- **情シス担当による初期設定** (利用者の登録、アクセス権の割り当て)

> 想定規模はおおむね **同時 50 名程度** の社内利用です。外部公開は想定していません。

## 7. よくある質問

**Q. データはクラウドに行きますか？**
　いいえ。すべて社内で完結し、社外にデータは出ません。

**Q. 既存のファイルサーバーを置き換えるのですか？**
　いいえ。既存サーバーはそのままで、そこへの「**安全な入口**」を追加するイメージです。

**Q. 社員の教育は大変ですか？**
　2 つのフォルダを並べた直感的な画面で、基本はマウス操作です。簡単な利用ガイドがあります。

**Q. 誰がアクセスできますか？**
　管理者が許可した人だけです。フォルダ単位でアクセス範囲を絞れます。

**Q. 何かあったとき、誰が触ったか分かりますか？**
　はい。全操作が記録され、表計算ソフト用ファイル (CSV) にも出力できます。

## 8. ちいさな用語集

| 用語 | やさしい説明 |
|---|---|
| CIFS / SMB | 社内の「共有フォルダ」を使うための一般的なしくみ |
| 踏み台サーバー | 直接つなげない場所へ、中継してアクセスするための中継サーバー |
| 監査ログ | 「いつ・誰が・何をしたか」の記録 |
| 自動更新 (ClickOnce) | アプリを配布し、新しい版を自動で入れ替える Windows のしくみ |
