⛩ Watashi 利用者マニュアル

パソコンが苦手な方でも大丈夫。社内ファイルサーバーへのファイルの出し入れを、最初から最後まで丁寧に説明します。

0このツールについて

Watashi（わたし）は、社内のファイルサーバー（共有フォルダ）に置いてあるファイルを、あなたのパソコンから安全に出し入れするためのアプリです。

たとえばこんなときに使います。

  • サーバーにある資料を自分のパソコンに取り出す（ダウンロード）
  • 自分が作った資料をサーバーに置く（アップロード）
  • サーバーのフォルダを整理する（フォルダ作成・名前変更・削除）

3つの「場所」を覚えてください

このアプリには、ファイルの置き場所が大きく分けて2つ出てきます。これだけ覚えれば操作はぐっと分かりやすくなります。

ローカル（このPC）
あなたが今使っているパソコンの中。アプリの画面では左側に表示されます。アイコンは💻。
リモート（社内サーバー）
会社の共有ファイルサーバー。アプリの画面では右側に表示されます。アイコンは⛩（鳥居）。
接続場所（リモートの場所）
リモート側で「どの共有フォルダを見るか」の選択肢です。たとえば「経理部ドキュメント」「営業部共有」など。あなたが見られる場所は管理者が決めています（→第16章）。
このアプリの大事な考え方 左（自分のPC）と右（社内サーバー）の間で、ファイルを「上げる（アップロード）」「下ろす（ダウンロード）」のが基本動作です。FFFTP などの「2画面ファイル転送ソフト」を使ったことがある方は、それとほぼ同じ感覚です。
接続先は変更できません（それで正常です） どのサーバーにつなぐか、どんな機能が使えるかは、配布時に管理者があらかじめ固定しています。利用者側で接続先を入力したり変えたりする画面はありません。「サーバーアドレスはどこに入れるの？」と探す必要はありません。

1インストールと起動

1-1. 初回だけ：インストール

  1. 管理者から案内されたインストール用のURLを、ブラウザ（Edge など）で開きます。
    例： https://watashi.internal/install/Watashi.Client.application
  2. 画面の指示にしたがってインストールを進めます。完了すると、スタートメニュー（および必要に応じてデスクトップ）に「Watashi」が追加されます。

1-2. 2回目以降：起動のしかた

  1. スタートメニュー（またはデスクトップ）の「Watashi」をクリックして起動します。
  2. 起動すると、最初に新しいバージョンがないか自動でチェックします。新しい版があればその場で適用されてから起動します（あなたの操作は不要です）。
  3. 続いてログイン画面が開きます。
通常は「Watashi」のショートカットから起動してください スタートメニュー／デスクトップの「Watashi」から起動すると、ClickOnce がアプリ起動前に自動更新を確認します。exe ファイルを直接ダブルクリックした場合も、アプリ起動直後に公開版を確認し、新しい版があれば更新を開始してから終了します。
起動時に「更新しています」と出たら 新しい版を適用している最中です。スキップはできません（必須更新）。終わるまで少し待つと、自動で起動します。

2ログイン

起動するとログイン画面が開きます。接続先サーバーはすでに設定済みなので、あなたが入力するのは「ユーザー名」と「パスワード」だけです。

2-1. ログインの手順

  1. ユーザー名を入力します。（管理者から伝えられたものです）
  2. パスワードを入力します。初回のパスワードは管理者から伝えられます。
  3. ログイン ボタンを押します（Enter キーでもログインできます）。

2-2. 👁 目玉アイコン（パスワードの確認）

パスワード欄の右端にある👁 目玉アイコンを押すと、隠れているパスワードを一時的に文字として表示できます。打ち間違いの確認に便利です。もう一度押すと、また隠れます。

キーボードだけでも切り替え可能 パスワード欄にカーソルがある状態で Alt ＋ P を押しても、表示／非表示を切り替えられます。

2-3. 「このPCを記憶する」

チェックを入れてログインすると、次回からは自動でログインされ、ユーザー名・パスワードの入力を省略できます。詳しくは第19章で説明します。

2-4. 接続テスト

画面下の 接続テスト を押すと、「サーバーにちゃんとつながるか」だけを確認できます。ログインできないときの切り分けに使います。

  • 結果が ✓ 接続できました。 なら、サーバーへの通信はできています（あとはユーザー名・パスワードの問題）。
  • ✗ ... と出たら、ネットワークやサーバー側の問題の可能性があります。管理者に連絡してください。
接続テスト画面でできること この画面は接続先の確認と疎通テストだけを行うもので、接続先を書き換えることはできません（接続先は管理者が固定しています）。現在の接続先サーバーのアドレスと、ドラッグ＆ドロップが有効か無効かも、ここで確認できます。

2-5. パスワードの期限が近いとき

パスワードの有効期限まで残り少ない（既定では14日以内）と、ログイン後に次のようなお知らせが出ます。早めに変更してください（変更方法は第20章）。

パスワードの有効期限まで残り 7 日です。期限までに変更してください。

3初回パスワード変更

初めてログインしたとき、またはパスワードの期限が切れたとき・管理者がリセットしたときは、ログインの直後にパスワード変更画面が必ず表示されます。ここで新しいパスワードを決めるまで先に進めません。

3-1. パスワードのルール（必須条件）

新しいパスワードは、次の条件をすべて満たす必要があります。

条件説明
12文字以上短いパスワードは設定できません。
英大文字を1文字以上A〜Z のどれか。
英小文字を1文字以上a〜z のどれか。
数字を1文字以上0〜9 のどれか。
記号を1文字以上! # @ - などの記号。
判定例理由
NG ✗password123大文字・記号がない
NG ✗Short1!12文字に足りない
NG ✗nouppercases123!大文字がない
OK ✓Spring2026!Welcomeすべて満たす
OK ✓Watashi#Tool-2026すべて満たす

3-2. 手順

  1. 現在のパスワードを入力します。（初回は管理者から伝えられたもの）
  2. 新しいパスワードを、上のルールを満たすように入力します。
  3. 新しいパスワード（確認）に、もう一度まったく同じパスワードを入力します。
  4. 変更 を押します。成功するとメイン画面に進みます。
「新しいパスワードと確認が一致しません。」と出たら 2番目と3番目の欄の文字が違っています。👁 目玉アイコンで両方を表示して、同じ文字になっているか確認してください。

4メイン画面の見かた

ログインが終わると、メイン画面が開きます。画面は大きく6つの部分でできています。まずは「どこに何があるか」をざっくり覚えましょう。

番号名前内容
①ヘッダー左に鳥居ロゴと「Watashi」。右にログイン中のユーザー名・接続方式（HTTPS/HTTP）・管理ボタン（管理者のみ表示）・⟳ 更新・⏻ ログアウト・ⓘ 情報。
②ツールバー⬆ アップロード と ⬇ ダウンロード の2つのボタン。
③ローカルペイン（左）💻 あなたのパソコンの中のフォルダ・ファイル。
④リモートペイン（右）⛩ 社内サーバーのフォルダ・ファイル。上部の「接続場所」で見る場所を切り替えます。
⑤ステータスバー下端。接続状態（緑の●）、直近の操作結果やエラー、ログイン中のユーザー名を表示。
⑥転送バーアップロード／ダウンロード中だけ現れる進捗バー。速度・残り時間・キャンセルも表示。
赤い帯（エラーバナー）について 操作が失敗したときは、画面上部に赤い帯でエラー内容が大きく表示されます。内容を読んだら、帯の右にある ✕ で閉じられます。
長い名前は、マウスを乗せると全部見える ファイル名やパスが長くて「…」で省略されているときは、その行にマウスカーソルを乗せる（ホバーする）と、省略されていない全文がポップアップ（ツールチップ）で表示されます。

5フォルダの移動（中を見る）

左右どちらのペインでも、フォルダの中に入ったり、ひとつ上に戻ったりする方法は同じです。

5-1. フォルダの中に入る

  • フォルダ（📁）をダブルクリックすると、その中に入ります。
  • フォルダを選んで Enter キーでも入れます。

5-2. ひとつ上のフォルダに戻る

  • 一覧のいちばん上にある 📁 ..（点が2つ）をダブルクリックすると、ひとつ上の階層に戻ります。
  • ツールバーの ⬆ ボタン、Backspace キー、Alt＋↑ でも上に戻れます。
.. が薄く（グレーに）なっていて押せないとき そこがあなたに許可された範囲のいちばん上です。それより上のフォルダは見る権限がないため、移動できません。マウスを乗せると この場所より上には移動できません と表示されます。これは故障ではなく、正常な制限です。

5-3. 戻る／進む

ブラウザの「戻る・進む」と同じように、ひとつ前に見ていたフォルダに戻れます。

操作ボタンキーボード
戻る（前に見ていた場所へ）◀Alt＋←
進む▶Alt＋→
ひとつ上へ⬆Alt＋↑ / Backspace
再読み込み（最新の状態に更新）⟳F5

5-4. パスを直接入力して移動

行き先がわかっている場合は、パス入力欄に直接打ち込んで Enter、または横の 移動 ボタンで一気に移動できます。

  • ローカル例： D:\work\2026
  • リモート例： /dept-A/2026
パス欄はクリックすると全文が選ばれます パス入力欄をクリックすると、中の文字がすべて選択された状態になります。そのまま Ctrl＋C で今いる場所のパスをコピーできて便利です。もう一度クリックすると、ふつうにカーソルを置いて一部だけ直せます。

5-5. 📂 ボタンでフォルダを選ぶ（ローカルのみ）

ローカルペインのパス欄の隣にある 📂 ボタンを押すと、Windows のおなじみのフォルダ選択ダイアログ（エクスプローラ風のツリー）が開きます。目的のフォルダをツリーから選んで一発で移動できます。パスを手入力するのが苦手な方におすすめです。

5-6. 「このフォルダは空です」などの案内

表示意味
📂 このフォルダは空です中身がないだけ。問題ありません。
🔍 一致するファイルやフォルダがありません絞り込み検索の条件に合うものが無い（→第7章）。検索文字を消すと元に戻ります。
未接続 ／ リモート接続先が未選択です右上の「接続場所」をまだ選んでいない状態。場所を選んでください。
⛩ アクセスできるリモート場所がありませんあなたに見られる共有がまだ割り当てられていない。管理者に依頼してください（→第16章）。

6⚠ ファイルはダブルクリックでは開きません

とても大事な仕様です このアプリでは、ファイル（📄）をダブルクリックしても、何も起きません。Excel や PDF などが、その場で開いたりはしません。これは不具合ではなく、わざとそうしている設計です。

「ダブルクリックで開く」ができるのはフォルダ（📁）だけです。フォルダをダブルクリックすると中に入りますが、ファイルをダブルクリックしても Enter を押しても、右クリックの「開く / 展開」を選んでも、ファイルの中身は開きません。

6-1. では、ファイルの中身を見るには？

リモート（サーバー）のファイルを見たいとき

  1. そのファイルを、まず自分のパソコンにダウンロードします（→第9章）。
  2. ダウンロードした自分のパソコンのファイルを、いつもどおり Excel や PDF ビューアなどで開きます。

ローカル（自分のPC）のファイルを見たいとき

  1. そのファイルを右クリックして 「エクスプローラで表示」 を選びます。
  2. Windows のエクスプローラがそのファイルを選んだ状態で開くので、エクスプローラ側でダブルクリックして開きます。
なぜこんな仕様なの？ Watashi は「ファイルを安全に運ぶための道具」に役割をしぼっています。中身を勝手に開いてしまうと、意図しないアプリが立ち上がったり、編集したつもりがサーバーに反映されない、といった混乱が起きます。「見る・編集するのはダウンロードしてから」とルールを単純にすることで、誤操作を防いでいます。

7絞り込み（検索）と並べ替え

7-1. 名前で絞り込む（検索）

各ペインのパス欄の下に 🔍 絞り込み欄があります。ここに文字を入力すると、その文字を名前に含むファイル・フォルダだけが表示されます（部分一致）。

  • 例：2026 と入れると、名前に「2026」を含むものだけが残ります。
  • 右端の × を押すと、絞り込みを解除して全部表示に戻ります。
絞り込みは「いま表示しているフォルダの中」だけ 絞り込みは、今開いているフォルダの中身に対してかかります。サブフォルダの奥まで横断して探すものではありません。

7-2. 並べ替え（ソート）

一覧の上にある列の見出し（名前 / サイズ / 更新）をクリックすると、その項目で並べ替わります。もう一度クリックすると、昇順↔降順が切り替わります。

クリックする見出し並び順
名前あいうえお／アルファベット順
サイズファイルの大きさ順
更新更新日時の新しい／古い順

8アップロード（自分のPC → サーバー）

アップロード＝自分のパソコンのファイルを、社内サーバーに置くことです。「左から右へ」運びます。

8-1. 手順

  1. 左ペイン（ローカル）で、送りたいファイル（またはフォルダ）をクリックして選択します。
  2. 右ペイン（リモート）で、置きたい先のフォルダを開いておきます。必要なら上部の「接続場所」も選びます。
  3. ツールバーの ⬆ アップロード を押します。
  4. 進捗バーが出て、終わると アップロード完了: ◯◯ と表示されます。
右クリックからでもOK 左ペインでファイルを右クリック →「アップロード」でも同じ動作です。

8-2. すでに同じ名前のファイルがあるとき（上書き確認）

置き先に同じ名前のファイルがある場合は、上書きするか確認されます。

◯◯ はリモートに既に存在します。上書きしますか？

  • はい：古いファイルが新しいもので置き換わります。
  • いいえ：アップロードを取りやめます。

8-3. フォルダごとアップロード

ファイルだけでなく、フォルダを丸ごとアップロードもできます。フォルダを選んで ⬆ アップロード すると確認が出ます。

フォルダ "◯◯" をフォルダごとアップロードしますか？

置き先に同じ名前のフォルダがある場合は、中身を結合（マージ）し、同じ名前のファイルは上書きしてアップロードします。

8-4. 進捗・速度・残り時間・キャンセル

転送中は画面下に進捗バーが出ます。

  • 転送中: ファイル名 … 今送っているファイル
  • 速度（例：12.3 MB/s）と 残り時間の目安
  • %（パーセント） … 全体の進み具合
  • キャンセル … 押すと途中で中止できます（アップロードをキャンセルしました。）
ファイルの大きさに制限はありません 大きなファイルでも送れます。ただしネットワークが不安定だと途中で止まることがあります。その場合はもう一度試してください。
また、1つの転送が終わるまで、次の転送は始められません。複数同時には走りません（「別の転送が進行中です。完了までお待ちください。」と出ます）。

9ダウンロード（サーバー → 自分のPC）

ダウンロード＝社内サーバーのファイルを、自分のパソコンに取り出すことです。「右から左へ」運びます。

9-1. 手順

  1. 右ペイン（リモート）で、取り出したいファイルをクリックして選択します。
  2. 左ペイン（ローカル）で、保存したい先のフォルダを開いておきます。
  3. ツールバーの ⬇ ダウンロード を押します（右クリック →「ダウンロード」でも可）。
  4. 進捗バーが出て、終わると ダウンロード完了: ◯◯ と表示されます。
保存先は「左ペインで今開いているフォルダ」 ダウンロードしたファイルは、左ペイン（ローカル）で今表示しているフォルダに保存されます。先に左ペインで保存したい場所を開いておきましょう。

9-2. 途中で失敗しても、壊れたファイルは残りません

「.part」という仕組みで安全にダウンロード ダウンロード中は、いったん ファイル名.part という一時ファイルに書き込み、最後まで完了したときだけ正式な名前に変わります。通信が切れたりキャンセルしたときは、この .part ファイルは自動で消えるので、中途半端な壊れたファイルがフォルダに残りません。

9-3. 同じ名前・フォルダごと

アップロードと同じく、保存先に同名ファイルがあると上書き確認が出ます。

◯◯ はローカルフォルダに既に存在します。上書きしますか？

フォルダを選んでダウンロードすると、フォルダごと丸ごと取り出せます（中身も全部）。

10ドラッグ＆ドロップ（マウスでつかんで運ぶ）

この機能は使えない場合があります ドラッグ＆ドロップが使えるかどうかは、配布時に管理者が決めています。使えるかどうかは、ログイン画面の 接続テスト 画面で「ドラッグ＆ドロップ転送: 有効／無効」と確認できます。無効の場合は、ボタン操作（第8・9章）を使ってください。

有効になっている場合は、マウスでファイルをつかんで運ぶだけで転送できます。

つかむ場所落とす場所結果
左ペイン（ローカル）の項目右ペイン（リモート）アップロード
右ペイン（リモート）の項目左ペイン（ローカル）ダウンロード
Windowsのエクスプローラのファイル右ペイン（リモート）アップロード（エクスプローラから直接）

複数のファイルをまとめて選んでから運ぶこともできます。同名の項目は上書きされる旨の確認が出ます。

11まとめて転送（複数選択）

ファイルは1つずつでなく、まとめて転送できます。

  • Ctrl を押しながらクリック … 飛び飛びに複数選択
  • Shift を押しながらクリック … 上から下まで範囲をまとめて選択

複数選んだ状態で ⬆ アップロード または ⬇ ダウンロード を押すと、最初に1回だけ確認が出て、まとめて転送します。

3 件をアップロードします。リモートの同名項目は上書きされます。よろしいですか？

12新しいフォルダを作る

13-1. リネームのルール（できないこと）

ルール説明

14削除

  1. 消したいファイル／フォルダを選びます。
  2. Delete キーを押す（または右クリック →「削除」）。
  3. 確認ダイアログが出ます。内容を読んで、よければ OK。

リモートの削除には削除（Delete）権限が必要です。無いと 削除失敗: 削除権限がありません。 と出ます。

16権限（あなたにできること）

「アップロードできない」「削除できない」「そもそもサーバーのフォルダが見えない」——それは故障ではなく、あなたに割り当てられた権限によるものかもしれません。この章では、その仕組みを説明します。

権限は、管理者が決めています 誰が・どの共有フォルダの・どの操作（見る／置く／消す／名前を変える）をできるかは、すべて管理者が一人ひとりに設定しています。あなた自身で自分の権限を変えることはできません。必要な操作ができないときは、管理者に「この場所で◯◯がしたい」と依頼してください。

16-1. 4つの権限

権限は、共有フォルダごと（さらにその中のサブフォルダごと）に、次の4種類を組み合わせて与えられます。

権限できることこれが無いと…
Read（読み取り）リモートの一覧表示・フォルダ移動・ダウンロードそもそも中身が見えず、ダウンロードもできません。
Write（書き込み）アップロード・新規フォルダ作成アップロード・フォルダ作成ができません。
Delete（削除）ファイル／フォルダの削除削除ができません。
Rename（名前変更）同じフォルダ内での名前の変更名前の変更ができません。

16-2. よくある権限パターンと、できること

管理者は、たとえば次のような「テンプレート（ひな型）」を組み合わせて割り当てます。あなたがどのパターンかは、管理者に確認できます。

（Readだけ）		 ✓✓✗✗✗
読取＋書込 ✓✓✓✗✗
読取＋書込＋名前変更 ✓✓✓✗✓
フルアクセス ✓✓✓✓✓
「読取のみ（Readだけ）」の人ができること・できないこと

❌ できない：アップロード／新規フォルダ作成／削除／名前の変更（やろうとすると「◯◯権限がありません」というエラーになります）
＝「サーバーの資料を見て、必要なものを手元に落とすだけ」の使い方になります。サーバー側を書き換える操作は一切できません。

16-3. 同じ共有でも、フォルダによって権限が違うことがあります

権限は「共有まるごと」ではなく、共有の中のフォルダ単位でも設定できます。たとえば同じ共有の中でも——

  • /dept-A … フルアクセス（自由に編集できる自部署フォルダ）
  • /shared/templates … 読取のみ（みんなの共通ひな型なので、見るだけ）

——のように、場所ごとに違うことがあります。「あっちのフォルダでは消せたのに、こっちでは消せない」というのは、こうした設定のためです。

16-4. リモートに何も表示されないとき

右ペインに ⛩ アクセスできるリモート場所がありません
「管理者にユーザー権限の追加を依頼してください」と出る場合、あなたにはまだ1つも共有が割り当てられていません。管理者に、使いたい共有フォルダへのアクセス権を依頼してください。

18ログアウト／自動ログアウト

18-1. 自分でログアウトする

画面右上の ⏻ ボタンを押します。確認ダイアログ ログアウトしますか？ が出るので OK。ログイン画面に戻ります。

ログアウトすると、このPCの自動ログイン情報も消えます（次回はまた手入力ログインになります）。共有のパソコンを使っているときは、離席・終業時に必ずログアウトしましょう。

18-2. 何もしないと自動でログアウトされます

アイドルタイムアウト 一定時間、何も操作しないでいると、自動的にログアウトされます（初期設定は30分。社内の方針で管理者が変更している場合があります）。そのときは 無操作のためログアウトしました。再ログインしてください。 と表示されます。慌てず、もう一度ログインしてください。

18-3. 突然「再ログインしてください」と出たら

セキュリティのしくみ（同じアカウントが複数の場所から使われた疑いを検知するなど）により、安全のため強制的にログアウトされることがあります。もう一度ログインすれば使えます。頻繁に起きる場合は管理者に相談してください。

19「このPCを記憶する」（自動ログイン）

ログイン画面で「このPCを記憶する」にチェックを入れてログインすると、次回起動からユーザー名・パスワードの入力なしで自動ログインできます。自分専用のパソコンなら便利な機能です。

19-1. しくみと注意点

項目内容
記憶のされ方「PC名 ＋ Windowsのユーザー名 ＋ このPC専用の合言葉（デバイストークン）」で本人確認します。パスワードそのものは保存されません。
保存場所Windowsの安全な保管庫（Credential Manager）に暗号化して保存。同じPCの別のWindowsユーザーからは読めません。
1人1台まで記憶できるのは1人につき1台。別のPCで「記憶する」をオンにすると、前のPCの記憶は無効になります。
解除される場合ログアウトしたとき／管理者が「全デバイス失効」をしたとき（退職対応など）／セキュリティ上の理由で強制解除されたとき。
共有パソコンでは使わないで 他の人も使うパソコンで「このPCを記憶する」をオンにすると、別の人があなたとしてログインできてしまう恐れがあります。自分専用のPCでだけ使ってください。
HTTP接続のとき 会社の設定によっては自動ログインが安全のため禁止されていることがあります。チェックを入れても自動ログインがすぐ切れる場合は、管理者に確認してください（HTTPSでの接続が推奨です）。

20パスワードの管理

20-1. パスワードを変えたいとき

このアプリには、ふだん（期限内）に自分からパスワードを変える専用ボタンは用意されていません。パスワード変更画面は、次のタイミングで自動的に表示されます。

  • 初めてログインしたとき
  • パスワードの有効期限が切れたとき（初期設定は90日）
  • 管理者がパスワードをリセットしたとき

このとき表示される画面で、新しいパスワードを設定します（やり方は第3章と同じ）。

今すぐ変えたいときは 期限前でもどうしても変更したい場合は、管理者にパスワードのリセットを依頼してください。次回ログイン時に変更画面が出ます。

20-2. パスワードを忘れた／アカウントがロックされた

自分では解除できません。管理者に連絡してください。管理者がロック解除やパスワードのリセットをしてくれます。

21困ったとき（トラブル＆エラー集）

21-1. ログインできない

画面に出る言葉意味と対処
ユーザー名またはパスワードが違います。入力ミスの可能性。大文字・小文字、CapsLock、数字や記号をよく確認。👁 目玉アイコンで表示して確認しましょう。
アカウントがロックされています。管理者に連絡してください。パスワードを連続で間違えるとロックされます（既定15回）。管理者にロック解除を依頼。
しばらく時間を置いてから…／429 Too Many Requests短時間にログインを試しすぎ。1分ほど待ってからもう一度。
通信エラー: …ネットワークかサーバーの問題。接続テストで疎通を確認し、ダメなら管理者へ。
パスワード変更画面が出る期限切れ／管理者リセット。新しいパスワードを設定すれば進めます（第3章）。

21-2. ファイル操作でつまずく

症状対処
ファイルをダブルクリックしても開かない仕様です。ダウンロードしてから開きます（第6章）。
右ペインが空っぽ／何も見えない「接続場所」を選んでいないか、権限が無い可能性。場所を選ぶ→それでも空なら管理者へ（第16章）。
…権限がありません。その操作の権限が無い。管理者に依頼（第16章）。
.. が押せない（グレー）許可された範囲のいちばん上。正常な制限です。
リネームでは親ディレクトリを変更できませんリネームで別フォルダへ移動はできません。同じフォルダ内で名前を変えるのみ（第13章）。
大きいファイルが途中で止まるネットワークの一時的な不調か、セッション切れの可能性。もう一度試す。
ホスト/共有が見つかりません管理者がサーバー設定を変更・削除した可能性。管理者に確認。

21-3. 起動・更新まわり

症状対処
起動時に更新の進捗が出る自動更新中。終わるまで待つ（必須更新でスキップ不可）。
更新しても新しい版にならないexeを直接起動している可能性。スタートメニュー／デスクトップの「Watashi」から起動する（第1章）。
配布設定 (deployment.json) …と出て起動しない配布パッケージの不備。利用者では直せません。管理者に連絡してください。
自動ログインがすぐ切れるサーバー設定でHTTP自動ログインが禁止されている可能性。管理者に確認、またはHTTPSで接続（第19章）。
困ったら、まずこの3つ ① F5 で更新してみる　② 一度ログアウト→ログインし直す　③ それでもダメなら、画面の赤い帯（エラー文）をそのまま管理者に伝える。エラーの文章が解決の手がかりになります。
