このフォルダに、マニュアルに表示するスクリーンショット画像（PNG）を入れます。

■ 入れ方
1. Watashi の画面でスクリーンショットを撮ります
   （Windows なら  Windows + Shift + S）
2. 下の「ファイル名」のとおりの名前で、このフォルダに PNG 形式で保存します
3. ブラウザで index.html を開き直す（F5）と、差し替え枠が画像に置き換わります

■ ファイル名の一覧（最初に用意されている差し替え枠）
  01-install.png       … インストール画面
  02-login.png         … ログイン画面
  03-main.png          … メイン画面の全体
  04-folderpicker.png  … 📂 フォルダ選択ダイアログ

※ 画像をまだ置いていない枠は、点線のカメラ枠（差し替え案内）として表示されます。
※ 枠を増やしたいときは index.html の付録「スクリーンショットの差し替え方」を参照。
