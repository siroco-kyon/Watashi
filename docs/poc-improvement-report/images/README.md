# スクリーンショット差し替え手順

`docs/poc-improvement-report/index.html` には、以下 3 箇所にスクリーンショットの差し替え枠（点線の灰色ボックス）を用意しています。
このフォルダに **同じファイル名** で画像を置くだけで、`index.html` を開いたときに自動でその画像に置き換わります（HTML の編集は不要）。

| ファイル名 | 挿入箇所 | 撮ってほしい画面 |
|---|---|---|
| `shot-personal-settings.png` | 第3章「3-2. 自分の使い方に合わせたい」 | 新設した「個人設定」画面（起動時に開く場所・見た目・色分けルールが見えている状態） |
| `shot-home.png` | 第5章「主な改善のビフォー／アフター」 | 更新版のホーム画面（ダークモード表示で、一覧の選択行と下部の転送状況欄の進捗バーが見える状態） |
| `shot-transfer-center.png` | 第5章「主な改善のビフォー／アフター」 | 転送センター（状態フィルターと詳細表示が見えている状態） |

## 手順

1. 実際の画面をキャプチャする（Windows は `Win + Shift + S`）。
2. ファイル名を上表のとおりに変更する（例: `shot-home.png`）。
3. このフォルダ（`docs/poc-improvement-report/images/`）にコピーする。
4. `docs/poc-improvement-report/index.html` をブラウザで開き直せば、その枠に画像が自動表示されます。

## 推奨サイズ・注意点

- 形式は PNG 推奨（`.png`）。JPEG を使う場合は拡張子も含めて `index.html` 側の `<img src="...">` を書き換えてください。
- 横幅 1400〜1800px 程度、横長（16:10 前後）で撮ると枠にきれいに収まります。
- 会議で映しても問題ない状態（実在の社員名・機密ファイル名などが映り込まないよう、テスト用データで撮影）にしてください。
- 差し替え箇所を増やしたい場合は、`index.html` 内の `class="shot"` を検索すると同じ構造をコピーして追加できます。
- 図中の2000件は1回の読み込み単位です。続きがある場合は「さらに読み込む」で追加でき、一覧全体の上限ではありません。
- 静止画だけではキーボード操作の継続は確認できません。更新版の受入時には、Enter→上下キー→Backspace、F5、削除後の選択、読み込み中のF6／Ctrl+L／Ctrl+Fも実際に操作して確認してください。撮影・受入確認の実施日とClientバージョンは別途記録します。
