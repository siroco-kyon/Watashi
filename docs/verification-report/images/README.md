# スクリーンショット差し替え手順

`docs/verification-report/index.html` には、以下 3 箇所にスクリーンショットの差し替え枠（点線の灰色ボックス）を用意しています。
このフォルダに **同じファイル名** で画像を置くだけで、`index.html` を開いたときに自動でその画像に置き換わります（HTML の編集は不要）。

| ファイル名 | 挿入箇所 | 撮ってほしい画面 |
|---|---|---|
| `shot-login.png` | 第1章「概要」 | ログイン画面（「接続テスト」成功時の表示） |
| `shot-transfer.png` | 第3章「検証結果（機能領域別の内訳）」 | メイン画面でのファイル転送操作（進捗バーが見えている状態） |
| `shot-admin-audit.png` | 第4章「重点確認ポイント」 | 管理画面の監査ログ画面（操作履歴の一覧） |

## 手順

1. 実際の画面をキャプチャする（Windows は `Win + Shift + S`）。
2. ファイル名を上表のとおりに変更する（例: `shot-login.png`）。
3. このフォルダ（`docs/verification-report/images/`）にコピーする。
4. `docs/verification-report/index.html` をブラウザで開き直せば、その枠に画像が自動表示されます。

## 推奨サイズ・注意点

- 形式は PNG 推奨（`.png`）。JPEG を使う場合は拡張子も含めて `index.html` 側の `<img src="...">` を書き換えてください。
- 横幅 1400〜1800px 程度、横長（16:10 前後）で撮ると枠にきれいに収まります。
- 社外・会議で映しても問題ない状態（実在の社員名・機密ファイル名などが映り込まないよう、テスト用データで撮影）にしてください。
- 差し替え箇所を増やしたい場合は、`index.html` 内の `class="shot"` を検索すると同じ構造をコピーして追加できます。
