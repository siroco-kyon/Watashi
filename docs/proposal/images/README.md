# スクリーンショット差し替え手順

`docs/proposal/index.html` には、以下 3 箇所にスクリーンショットの差し替え枠（点線の灰色ボックス）を用意しています。
このフォルダに **同じファイル名** で画像を置くだけで、`index.html` を開いたときに自動でその画像に置き換わります（HTML の編集は不要）。

| ファイル名 | 挿入箇所 | 撮ってほしい画面 |
|---|---|---|
| `shot-main.png` | 第5章「後継ツール「Watashi」の全体像」（図4） | メイン画面（左右2ペインでファイル一覧が見えている状態） |
| `shot-audit-log.png` | 第7章「ねらい② 記録を「すぐ使える」ものにする」（図7） | 管理画面の操作ログ（監査ログ）画面（操作履歴の一覧） |
| `shot-permission.png` | 第8章「ねらい③ 経路と権限を安全にする」（図10） | 管理画面のユーザー権限設定画面（フォルダ×権限を設定している様子） |

## 手順

1. 実際の画面をキャプチャする（Windows は `Win + Shift + S`）。
2. ファイル名を上表のとおりに変更する（例: `shot-main.png`）。
3. このフォルダ（`docs/proposal/images/`）にコピーする。
4. `docs/proposal/index.html` をブラウザで開き直せば、その枠に画像が自動表示されます。

## 推奨サイズ・注意点

- 形式は PNG 推奨（`.png`）。JPEG を使う場合は拡張子も含めて `index.html` 側の `<img src="...">` を書き換えてください。
- 横幅 1400〜1800px 程度、横長（16:10 前後）で撮ると枠にきれいに収まります。
- 社外に見せても問題ない状態（実在の社員名・機密ファイル名などが映り込まないよう、テスト用データで撮影）にしてください。
- 差し替え箇所を増やしたい場合は、`index.html` 内の `class="shot"` を検索すると同じ構造をコピーして追加できます。
